# 🚀 My Personal Portfolio Website

A sleek, responsive, and modern personal portfolio website built to showcase my software engineering journey, technical skillset, and featured projects. 

---

## ✨ Features

* **Fully Responsive:** Optimized for a seamless experience across mobile, tablet, and desktop screens.
* **Project Showcase:** Interactive grid displaying featured applications with direct links to live demos and source code.
* **Dynamic Experience Timeline:** A clean visual walkthrough of my career milestones and education.
* **Contact Integration:** A fully functional contact form to get in touch with me directly.
* **Performance Focused:** Built with modern web practices ensuring fast load times and clean accessibility.
